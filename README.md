## Задания варианта

### Средняя сложность

1. №3 — вычисление факториала числа.
2. №5 — получение списка простых чисел до 100.
3. №9 — поиск минимального элемента списка.

### Повышенная сложность

1. №3 — генерация списка чисел Фибоначчи.
2. №7 — чтение текстового файла и подсчёт частоты слов.

## Структура проекта

```text
.
├── data/
│   └── sample.txt
├── lab2_tasks/
│   ├── __init__.py
│   ├── advanced.py
│   └── basic.py
├── tests/
│   ├── test_advanced.py
│   ├── test_basic.py
│   └── test_cli.py
├── .gitignore
├── main.py
└── README.md
```

Функции средней сложности находятся в `lab2_tasks/basic.py`, повышенной — в
`lab2_tasks/advanced.py`. Файл `main.py` позволяет запускать задания из
командной строки.

## Требования

- Python 3.10 или новее.
- Внешние библиотеки не требуются.

## Запуск заданий

Команды выполняются из корня проекта.

Факториал числа 5:

```bash
python main.py factorial 5
```

Простые числа до 100:

```bash
python main.py primes
```

Минимум в списке чисел:

```bash
python main.py minimum 5 -4 12 0
```

Первые восемь чисел Фибоначчи:

```bash
python main.py fibonacci 8
```

Частота слов в примере текстового файла:

```bash
python main.py words data/sample.txt
```

При подсчёте слова приводятся к одному регистру, а знаки препинания и цифры
не учитываются.

## Проверка

Для запуска всех тестов:

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют основные и граничные случаи для каждого задания, а также
работу командного интерфейса.
